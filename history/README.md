# Historical Evidence

This folder is for historical source manifests, legacy snapshots, and recovered evidence that may help reconstruct project history but must not be mistaken for current production source.

Rules:

- Keep current verified source in `apps-script/`, not here.
- Label every historical artifact with its date/release and provenance.
- Record hashes where available.
- Do not publish credentials, tokens, customer PII, or private operational data in this public repository.
- If a raw archive is unsafe for a public repository, store only a sanitized manifest/checksum here and retain the raw archive in an appropriate private location.
